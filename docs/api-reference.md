# API Reference

This page documents the complete public `pourpoint` API — every class, method,
and function exported from the package. It is generated from the type stubs in
the current checkout
(`pourpoint/__init__.pyi`). Release 0.4.0 includes snap-target extraction and
the diagnostics described here. For release-pinned behavior, use the
[0.4.0 reference](https://github.com/CooperBigFoot/pourpoint/blob/pourpoint-v0.4.0/crates/python/API.md).
Prose is thin where the stubs are signature-only and is being filled in over
time.

For a task-oriented tour, start with the [Quickstart](quickstart.md) and the
[Staged API](guide/staged-api.md) guide.
